## Stack técnica

- HTML5 / CSS3 / JavaScript vanilla (sem framework)
- SPA com hash routing namespaceado por módulo
- Quiz com persistência em `localStorage`
- SVGs autorais inline + imagens médicas reais licenciadas (CC0, CC BY, CC BY-SA, domínio público)
- Acessibilidade WCAG AA (ARIA, keyboard navigation, focus management)
- Cross-module deep links bidirecionais
- Componentes responsivos mobile-first

## Base evidencial

- **Diretrizes BR**: PCDT-IST 2022 (MS), Programa Reanimação Neonatal SBP 2022, Manual Técnico do Pezinho (PNTN), Guia TAN-MS nov/2025, Lei 14.154/2021 (triagem neonatal ampliada), Lei 13.002/2014 (linguinha), Lei 15.094/2025 (FOP/dedinho), Notas Técnicas MS
- **Internacionais**: CDC STD Guidelines 2021/2024, AAP Red Book, WHO, ILCOR/NRP 2020-2024, AAP/AHA, Joint Committee on Infant Hearing 2019, ACMG, Kimberlin et al. (NEJM 2015)
- **SBP**: Documentos Científicos dos Departamentos de Neonatologia, Cardiologia, Otorrino e Oftalmo Pediátrica
